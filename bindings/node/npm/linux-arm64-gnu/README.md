# `@diffy/node-linux-arm64-gnu`

The prebuilt [`@diffy/node`](https://www.npmjs.com/package/@diffy/node) binary for Linux arm64 with glibc 2.28 or newer. Install `@diffy/node`, not this package.

`THIRD_PARTY_NOTICES.md` lists the tree-sitter grammars compiled into it and their licenses. `RUST_NOTICES.md` lists the Rust crates compiled into it, with their licenses.
