# `@seatedro/diffy-linux-x64-gnu`

The prebuilt [`@seatedro/diffy`](https://www.npmjs.com/package/@seatedro/diffy) binary for Linux x64 with glibc 2.28 or newer. Install `@seatedro/diffy`, not this package.
